# HR Presence Analytics Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing employee attendance data to gain insights into:
- Presence
- Work From Home (WFH)
- Sick Leave (SL)

---

## 🎯 Objectives
- Monitor employee presence
- Analyze WFH patterns
- Track sick leave trends
- Support HR decision-making

---

## 🛠 Tools Used
- Power BI
- Power Query
- DAX

---

## 🔄 Data Preparation
- Data cleaning and validation
- Unpivoting columns using Power Query
- Optimized data model for analysis

---

## 📊 Dashboard Features
- KPI Cards (Presence %, WFH %, SL %)
- Employee-level Matrix
- Daily trend analysis using Area Charts
- Day-of-week analysis
